# Privacy Policy

ChemLimit non raccoglie dati personali.

- Non richiede account.
- Non usa tracking.
- Non usa analytics.
- Non invia le ricerche a server propri.
- Elabora CAS, nomi e sinonimi localmente nel browser usando il database incluso nell'estensione.
- La funzione ACGIH salva localmente nel browser la query CAS o nome solo per aiutare il content script a cercare nella pagina ufficiale `https://www.acgih.org/data-hub/`.
- Nessuna query ACGIH viene inviata a server propri di ChemLimit.

Quando l'utente apre link verso siti esterni, come ACGIH, ECHA, GESTIS, PubChem, eChemPortal o Buy Me a Coffee, la navigazione è soggetta alle privacy policy dei rispettivi siti. La funzione ACGIH apre una pagina esterna e usa la query salvata localmente solo all'interno del content script eseguito su quella pagina.
