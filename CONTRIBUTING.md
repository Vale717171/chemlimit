# Contributing

Thanks for taking a look at ChemLimit.

## Before opening a PR

- Open an issue first for bugs, data problems, or feature proposals.
- Keep proposals small, specific, and easy to verify.

## Please do not propose

- ACGIH scraping
- copying ACGIH TLV values into the extension
- broad feature creep unrelated to the core Italy-first workflow

## For regulatory data changes

- Indicate the legal or official source used.
- Indicate the source version or legal update.
- Keep the change narrow and reviewable.
- Run the dataset validation and build scripts before submitting.

## Preferred contribution style

- Small PRs
- Clear scope
- Verifiable behavior
- Minimal unrelated refactors
