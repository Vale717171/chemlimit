# Security Policy

If you believe you found a security issue in ChemLimit, please do not open a public GitHub issue with exploit details.

Instead, report it privately through the repository owner contact channel available on GitHub.

Please include:

- a short description of the issue
- affected files or feature area
- steps to reproduce
- potential impact

Project notes:

- ChemLimit does not operate its own backend services
- ChemLimit does not use user accounts
- ChemLimit processes data locally in the browser extension

That said, browser-extension security issues should still be treated seriously.
